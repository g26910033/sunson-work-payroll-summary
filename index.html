Sources & limits

資料基準、來源與使用限制

這是一份截至 2026/10/9 的人工整理快照，不會自動讀取後續班表、薪資單或匯率。

  • 班表與薪資：依參照對話中整理的 GoRoster 八週排班及四期 iPayroll 薪資單摘要。本次取得的參照內容未附原始薪資單 PDF，所以各期金額沒有在此重新對照原檔。
  • 計薪時數：只有四期雙週合計列為薪資單實績。單週拆分、休息扣時原因及第 8 週薪資都是估算／未核實；頁面不推定任何 10/9 以後班次已出勤。
  • 稅率參考：IRD 個人稅碼、PAYE 與 ACC earners' levy 說明。2026/27 ACC earners' levy 為 1.75%；個人退稅仍取決於實際全年收入、稅碼、雇主及其他應稅收入。
  • 匯率：18.07、17.67 與 18.10 為原對話記錄的 2026/10/9 星展牌告快照，未在本頁即時連線更新。頁面預設 18.10 為賣出價計算比較用台幣，不等於實際換匯成交價。
  • 免費託管：GitHub Free 個人方案包含公開儲存庫的 GitHub Pages；Pages 使用限制與服務條款。網站沒有設定到期日，持續提供仍取決於 GitHub 服務政策、帳號與儲存庫狀態。
  • 隱私：頁面不列員工姓名，不包含銀行帳號、住址、稅號、薪資單影像或聯絡方式；不使用分析追蹤或表單。網址可公開存取，搜尋引擎不索引標籤不是存取控制。

金額為紐幣（NZD）；台幣（TWD）換算四捨五入至整數。頁面內容用於個人收支整理，不取代雇主逐日工時紀錄、正式薪資單或 IRD 個別結算。
