# Sunson 工作與收支整理

繁體中文單頁靜態網站。薪資實績截至 2026/10/9；最新班表與全部預估已於 2026/10/11 重算。

## 新班表的更新規則

使用者要求：每次新班表到來，必須同步更新**全部班表、平均工時、各期稅前／稅後薪資、月薪、年度 PAYE、退稅、退稅平攤收入、儲蓄及相關台幣換算**，不得留下舊退稅值。

1. 將新班表完整日期、起訖時間及公布日期寫入 `forecast-data.json`；新增薪資單時也更新 `payslips` 的實績，保留原紀錄。
2. 執行 `python3 recalculate.py`。它會以同一份資料重新計算並更新網頁的所有模型區塊、最新班表、歷史班表及公布時程；周邊樣式不改動。
3. 核對稅前－PAYE＝稅後、平均是否包含最新週、全年 PAYE 與退稅是否更新、手機顯示、日期及隱私。以 `git diff --check` 檢查差異。
4. 只提交本次公開摘要與來源，push 後等待 Pages 部署完成，直接核對公開頁。

## 計算基準與限制

- `forecast-data.json` 是已去除個資的來源：九週原始班表、四期實際薪資、生活費及估算假設。不要加入信件全文、薪資單影像、銀行帳號、地址、稅號或聯絡資料。
- 目前平均排除第 1、5 週；新公布週必須列入，不因工時較少就自行排除。
- 每班 4 小時以上預設扣 30 分鐘無薪休息。已有薪資單的週，仍以薪資單時數按排班比例分攤，不再次扣休息。
- 未公布班表按最新平均推估；部分週按有效日數／7 暫估。未來班次不可標成已完成。
- 正常時薪 23.95，另加 8% 假期加給。前累計 20 小時 19.16 保留為既有實績，不在新雇主預估中擅自再套用。
- 2026/27 稅碼 M、ACC 1.75%。每個雇主各自按雙週薪資估扣 PAYE，再合併當年度已發薪收入計算全年所得稅與 ACC；預扣與全年負擔差額為退稅估值。
- 第一份至 2026/11/19；第二份暫定 11/20–2027/2/19；第三份 2027/3/15 起。第二、第三份的薪資、工時與雙週薪期都屬假設，確認後必須同步更新。
- 發薪周期由 2026/8/28 起每 14 天，對應結束於前週日的兩週期間。第三份暫估 3/26 發薪涵蓋 3/15–21，3/22 起若於 4/9 發薪歸下一年度。年度以發薪日為界，不把尚未發薪的三月班次硬算入同一年度。
- 退稅模型只包含列出的紐西蘭薪資；利息、其他收入及稅務抵免未納入。實際 IRD 結算與扣繳可能不同。
- 星展賣出 18.10 為 2026/10/9 11:50 台灣時間的歷史牌告；非即時匯率。紐幣換回台幣應看銀行買入價。換算金額同步重算。
- `index.html` 是公開網頁；各模型區塊以 `model:*` 註解標記，由 `recalculate.py` 同步產生。不使用框架或外部套件。
