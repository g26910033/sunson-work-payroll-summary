# Sunson 工作收支

繁體中文靜態網站：https://gpt.greenparty.org.tw/sunson-work-payroll-summary/

## 維護來源

- `forecast-data.json`：去識別化班表、實際薪資、使用者確認的條件、假設與匯率。
- `recalculate.py`：計薪、PAYE、年度稅額、退稅情境及靜態內容產生器，僅用 Python 標準函式庫。
- `page-template.html`、`site.css`、`site.js`：頁面來源、手機版樣式及瀏覽器內的情境試算。
- `index.html`：執行 `python3 recalculate.py` 產生；不要直接修改。

## 每次更新

1. 更新新班表或薪資實績，保留原紀錄。新週必須納入平均，不能因時數低就自行排除。每次重新查星展 NZD 即期買入／賣出，保留牌告時間及官方來源；紐幣換回台幣用買入價。
2. 執行 `python3 recalculate.py`，同步更新全部班表、工時、各期稅前／稅後、月薪、生活費後儲蓄、年度 PAYE／ACC／退稅、平攤及台幣換算。
3. 檢查 `git diff --check`、來源差異、手機呈現和試算互動。修改 CSS／JS 時更新 `model_revision` 避免舊快取。產生器會核對薪資單收支、M 公式與已付 PAYE、年度摘要。
4. 只提交本次檔案；push main 後等 Pages workflow 成功，再核對帶版本參數的公開頁。

- 每班滿 4 小時預設扣 30 分鐘無薪休息。已發薪時數保留實績，按班表比例拆分至週，不再扣一次。
- 累計前 20 小時時薪 19.16，其後 23.95；8% 假期加給已含在各期稅前。普通工資與假期加給分別取分，不在離職時重複加 8%。
- 2026/10/23 使用者確認：Sunson 到 11/19；後兩份仍未確定，維持 11/20–2027/2/19、2027/3/15 起的原計畫作情境。三個續工情境都保留已付薪資。
- 銀行最後更正為 **ASB Savings On Call**。官方現行 0.25% 自 2026/7/15 生效；撤回 BNZ／YouMoney／零利息與舊 1.5% 假設。實際餘額、已收利息及 RWT 未提供，薪資退稅基準先不計，網站提供本機試算。

## 稅務模型

- 使用 IRD 2026/27 M 公式：單期稅前按薪期年化後截元；算所得稅＋ACC，除 52 截至分，再換回薪期。五期已付 PAYE 均可精確重現。
- 年度所得稅按實際／假設發薪日逐筆計入 4/1–3/31，薪資 ACC 另按 1.75%（上限 156,641）計算。利息不加 ACC；RWT 另抵所得稅。
- 正常月薪按雙週 ×26÷12；生活費每週 310，月化 ×52÷12。未公布班次按平均計薪工時 ×有效日數÷7，整期一次計算，避免逐日循環小數造成半分差。
- 逐雇主算扣繳，首末不足整期仍用正常薪期；不能合併兩位雇主的薪資套一次 M 表。
- 目前薪資情境未達 IETC 最低年度所得 24,000，未加抵免。其他收入、稅務居民身分、海外收入及抵免資格仍可能影響結算。
- 三月班次若四月入帳歸下一稅年。尾薪暫用原薪期，實際提前結清或其他未付假期須再改估。
- 退稅情境範圍不是統計信賴區間，也不是 IRD 結算結果；不能將未確定工作視為已取得收入。

## 公開與隱私

公開資料只留日期、班次、職務及金額摘要。不可加入姓名、銀行帳號、地址、稅號、私人信件、薪資單 PDF／影像、聯絡資料或私人餘額。網頁試算輸入不儲存、不會由此頁程式上傳；公開網域會載入 Cloudflare 一般瀏覽統計。匯率與銀行利率均為有日期的查核快照。
